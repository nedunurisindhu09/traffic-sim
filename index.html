ABOUT THIS MODEL

Traffic is a system.

Flow State is a lightweight agent-based traffic model. Each vehicle follows a shortest available route, slows when another car is close, and waits its turn at junctions. Road width changes capacity; a flyover lets one stream pass above another.

It is an exploratory model, not a calibrated forecast. Try the same network at different arrival rates and see where queues form.
